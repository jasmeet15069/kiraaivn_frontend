Connect your laptop (or any other machine)

No SSH, no exposed ports, no router changes — your laptop makes an outbound-only connection to Jarvis and stays connected. Jarvis can never dial in on its own.

  1. Download agent_client.py from the backend repo onto the laptop.
  2. Install its one dependency: 
    pip install aiohttp
  3. Get a connection token from whoever runs the backend (it lives in the server's .env, never in this page or any repo).
  4. Run it, and leave the window open — closing it instantly cuts Jarvis's access: 
    python agent_client.py \
  --url wss://kira-chat.167-233-158-179.sslip.io/agent-ws \
  --name my-laptop --token YOUR_TOKEN
  5. Tell Jarvis (or whoever manages the backend) the name you chose, e.g. my-laptop — it gets added to connectors.json so it shows up here once connected.

Every command it's asked to run prints in that terminal window as it happens — that's your live audit log.
